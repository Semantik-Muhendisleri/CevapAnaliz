# Web arayüzü

Streamlit ile geliştirilecek. Planlanan ekranlar (3. hafta raporu):

1. Giriş ekranı (öğretmen / öğrenci rolü)
2. Soru listesi ve soru ekleme
3. CSV yükleme ve girdi kontrolü
4. Sonuçlar: filtreleme ve CSV indirme
5. Cevap ayrıntısı: benzerlik değeri, eksik kavramlar, puan düzeltme ve düzeltme geçmişi
6. Öğrenci sonuç ekranı
